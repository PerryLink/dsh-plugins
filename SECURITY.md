# Security policy

This repository is the public index and documentation site for the PerryLink DSH domain packages. It does not ship a runtime package.

## Reporting

Do not open a public issue for a vulnerability. Email **novelnexusai@outlook.com** with the affected package, version, a minimal reproduction, and the impact you believe it has.

## Scope

- In scope: the catalog data, generated documentation, install commands, and links in this repository.
- Out of scope: vulnerabilities in a member package; report those on the member repository.
- No bug bounty, SLA, customer data, or production-readiness claim. This is a public/synthetic alpha project.
