1. Three-level standards and checks

规范、判据与验收表面：先把「什么样算合格」写成可执行条款，再谈单个插件做得好不好。要给 DSH 投稿或验收插件，从这一组进。

仓库它做什么 · 关键差异
dsh-standards三层规范（ENTRY/FLOW/BOOST）的执行总入口：带一致性核查器、等级审计与规范原文；A–D 只是质量分档，不是认证或安全审计
dsh-plugin-spec以编号条款维护 DSH 插件规范原文，供核查器逐条执行；只维护规则文本与编号，不做认证、安全审计与收费评级
dsh-certification社区插件的公开规范、可机器校验的评分模型与带徽章的独立登记册；只做可复现的数据登记，不发布插件、不声称权威
dsh-clinic一次运行对插件做四层检测：包结构静态检查、cordis 契约扫描、动态沙箱冒烟与集合站清单校验；零依赖，只用 Node 自带能力
dsh-score对插件做五维质量评分（安装、维护、文档、安全、合规），产出风险卡与排行榜；只跑 gh 与 npm 取证，无证据就报 no-evidence
dsh-plugin-ready不装包、不启宿主，只读包内容做 ENTRY 静态预检（元数据、入口、patch、engines、README/LICENSE）；静态通过不等于认证
dsh-check-pack用一条命令把 53 个合规核查器按锁定版本装进当前 profile；包本身只负责安装，不含核查逻辑、不碰数据

3. Developer toolchain

从建仓到发布的一条命令行路径：脚手架、静态预检、安装与诊断、版本迁移、隔离试装。

仓库它做什么 · 关键差异
dsh-plugin-dev把新建、检查、测试、提交、升级收成一个 dsh-dev 入口，按流程分发给家族里的各专用命令；包名与命令名分开以免重名
dsh-plugin-devtools把 start、ready、tools、dev 四个小 CLI 收成一套命令家族，覆盖插件开发全程；本身不是运行时插件，也不做评分、排名与认证
dsh-plugin-start给一个包名即写出符合当前规范的最小插件骨架，含 package.json 与 cordis.patch.yml；只生成文件，不装依赖、不启宿主、不发布
dsh-plugin-tools列出、诊断 DSH 开发工具并打印可直接执行的安装命令；它自己从不安装或更新，也不做包审计与评分
dsh-scaffold把 20+ 插件重复手写的 Provider seam、审批门与 sanitize/pricing/judge 抽成共享 TypeScript 包；零运行时依赖
dsh-codemod读取目标仓库声明的 dsh 版本区间，套用对应走廊里有证据的迁移规则做只读扫描；不写被扫仓库、不联网、不起子进程

dsh-claude-move把 Claude Code、Codex、OpenCode 与 Hermes 的会话、记忆、技能和斜杠命令复制成可续聊的 DSH 会话；源文件只读、写入过审批门（🧊 已冻结）

5. Compliance checkers

这一组核查器形态相同：交一份材料，按随包版本化规则逐条核，输出「哪行、哪栏、差什么」；差异在材料类型和规则包，不在流程。

仓库它做什么 · 关键差异分类
dsh-customs-doc-check核对报关单证台账的十位商品编号、币制代码与单证编号重复，指出哪行哪栏差什么；只列能逐条指认的差异，不判申报是否属实compliance / trade
dsh-demurrage-ledger核对滞箱费台账的免箱期起算、还箱日期、超期天数与金额算式是否自洽，逐箱指出哪一栏差什么；纯内存计算，不判费用该由谁承担compliance / trade
dsh-export-ctl-check核对出口管制物项台账的受控标注、许可证号与发证日期、最终用途是否闭环，逐行指出哪一栏缺什么；离线运行，不判物项是否受控compliance / trade
dsh-forecast-penalty核对预测准确率考核台账的定义式与考核费用算式是否与配置相符，逐期指出哪栏差什么；不判达标与否，也不决定费用该不该收compliance / trade
dsh-hs-classify核对商品归类台账里编号与章、品目、子目的前缀层级是否逐级自洽，指出哪行哪栏差什么；不查税则，也不判断商品该归入哪个编号compliance / trade
dsh-lc-doc-check核对信用证交单核对表的单据种类、提交情况与两项日期是否自洽，逐条指出哪栏缺什么；只做机械核对，不解读条款、不判不符点compliance / trade
dsh-origin-rvc-check核对原产地判定台账的区域价值成分算式与协定口径，逐料件指出哪栏差什么；规则包不伪造引文，不下合规结论、不改原件compliance / trade
dsh-railway-window核对铁路施工天窗台账的起止时间与天窗时长、批准时长是否自洽，逐条指出哪栏差什么；分类口径由本机构配置，不判施工是否违章compliance / trade
dsh-fmea-table-check核对 FMEA 分析表的评分可运算性、RPN 乘积与高风险措施的责任人期限，指出哪栏差什么；不改原表，不评判打分是否恰当compliance / quality
dsh-ota-review-check核对在线点评回复台账的回复人与回复日期、未回复是否超出自填期限，逐条指出哪栏差什么；不判回复是否恰当、差评是否恶意compliance / quality
dsh-pipeline-check核对项目文件链条台账的环节顺序、批复与签署日期先后、文件编号唯一性，指出哪栏差什么；不判项目合规，也不判支出是否超概算compliance / quality
dsh-ppap-check核对 PPAP 提交要素清单的提交记录、受控要素版本与零件号提交等级是否齐全，指出哪栏差什么；不判 PPAP 能否批准compliance / quality
dsh-repair-order-qc核对机动车维修工单的数量单价乘积、明细合计与结算总额算式，逐项指出哪栏差什么；7 条规则各带条款出处，不判收费是否合理compliance / quality
dsh-review-reply-check核对审稿意见逐条回应表的回应覆盖与修改位置留痕，逐条指出哪栏缺什么；看不到稿件本身，不核对改动是否真的存在compliance / quality
dsh-spc-gbt-adapter核对控制图台账的控制限、中心线与 Cp/Cpk 是否符合定义式与常数表，指出哪栏差什么；不判过程是否受控、能力是否充分compliance / quality
dsh-warranty-calc核对质保索赔台账的质保期截止、质保里程与金额算式是否自洽，逐笔指出哪栏差什么；零依赖纯本地计算，不判索赔是否该受理compliance / quality
dsh-aqua-input-check核对水产养殖投入品记录的投入量、使用日期与休药期起捕关系，指出哪行哪栏差什么；不判水产品是否安全可食，不判用药是否恰当compliance / safety
dsh-drill-script-check核对应急演练脚本的指挥人、响应级别、所需资源与各环节时长合计，逐环节指出哪栏差什么；响应分级不内置，须填本单位口径compliance / safety

dsh-hazchem-check核对危险化学品台账的储存量与临界量关系、重大危险源判定是否自洽，逐种指出哪栏差什么；不判是否构成重大危险源、是否需备案compliance / safety
dsh-hidden-risk-map按关键词把安全隐患台账映射到工贸企业重大事故隐患判定标准的候选条款，报出台账缺口；只供人工复核，不判是否构成重大隐患compliance / safety
dsh-power-loss-split核对一条线路单周期线损材料中供电量、售电量、线损电量与线损率的除法与量平衡，每条命中带算式和容差；阈值由本机构配置compliance / safety

dsh-bid-ca-precheck核对投标符合性响应台账的响应、结论取值与高风险条款证明材料，指出哪行哪栏差什么；不判投标是否有效、是否构成实质性偏离compliance / tender
dsh-bid-qual-check核对投标人资格条件核对表的要求内容、实际情况与证明材料是否三者闭环，逐条指出哪栏缺什么；不核验原件，也不认定资格compliance / tender

7. Phocinae

Phocinae（斑海豹）是独立的一条决策线：百 M 级非生成式模型在本机做是/否、分类、路由与评分，不写作文、不调云 API。

仓库它做什么 · 关键差异

phocinae-mcp把 gate、classify、route、score 四项能力暴露成 MCP 工具，供只读 MCP 的编码代理直接调用；新旧两代协议并存

dsh-autotier🧊 冻结 — 按每个 turn 的确定性信号选强档或廉价档，只有低置信时才问裁判模型；弱档执行时拒绝破坏性命令并提示先升级，守卫出错则升级而非放行
dsh-budget🧊 冻结 — 把每次会话的预算、碳足迹与延迟算进一个面板，超限时在流上给出修正性错误而不编造模型输出；不改写请求，配置非法在挂载时即失败
dsh-cert-mcp🧊 冻结 — 以只读 MCP 服务暴露插件认证登记表：认证等级、快照日期与五维证据；零运行时依赖，走 stdio
dsh-claude-move🧊 冻结 — 把 Claude Code、Codex、OpenCode 与 Hermes 的会话、记忆、技能和斜杠命令复制成可续聊的 DSH 会话；源文件只读、写入过审批门
dsh-community-bench🧊 冻结 — 开一个应用内 Community Bench 页签，展示 dsh-score 的公开证据层，读所有人同一份公开登记表；不做本地打分、不发遥测
dsh-defend🧊 冻结 — 在官方 seam 上为提示注入、越狱与密钥泄露给出 deny / ask / block 决策；规则裁决已知模式，其余交检测层，失败关闭
dsh-draw🧊 冻结 — 把静态图像生成收成一个工具、多个引擎的路由，按健康度回退并记账用量；凭据以 apiKeyRef 引用环境变量，配额在调用引擎前检查，耗尽时给完整尝试记录
dsh-reach🧊 冻结 — 把任意工作区的审批与提问卡推到微信、Telegram、飞书等 IM 通道，让人在聊天里直接答复；首位发送者成为 owner、白名单为空即拒绝所有人，默认失败关闭
