## F1 · 大白话查询命中（自动，可复跑）

**问题**：一个不懂包名的人，用日常说法能不能在市场里搜到正确的插件？

**方法**：把 14 条任务式提问喂给 `market/index.json`，用与宿主一致的 CJK 二元组匹配（非模糊语义），看 top-3 是否命中。

**复跑**：

```bash
cd 04-build/dsh-plugins
node scripts/f1-retrieval.mjs        # 打印逐条结果与命中率
```

**2026-11-02 结果：12 / 14（86%）**

| 提问 | top-3 |
|---|---|
| 帮我把这堆发票查重 | 发票查重 / 发票三单匹配 / 发票台账核验 |
| 银行流水和账对不上 | 银行流水对账 |
| 合同缺哪些条款 | 合同条款体检 / 劳动合同体检 / 合同到期续签 |
| 考勤加班超时了吗 | **未命中**（尚无考勤包） |
| 这个月碳排放多少 | 用电碳排放（范围二） |
| 投标资格够不够 | 投标资格条件审查 / 投标符合性预检 / 投标响应覆盖检查 |
| 施工资料齐不齐 | 施工资料齐套检查 / 工资核算复核 / 本地资料库检索 |
| 病历首页质控 | 病案首页质控 |
| 门店要不要补货 | **未命中**（尚无补货包） |
| 供应商报价比一比 | 询价比价 |
| 发票和入库单对一下 | 发票三单匹配 / 发票查重 / 发票台账核验 |
| 员工合同到期该续了吗 | 合同到期续签 / 劳动合同体检 / 合同法务套件 |
| 进口报关单和箱单对得上吗 | 报关单证比对 / 滴答清单对接 / 进口单证核对 |
| 进度款能结多少 | 进度款审核 |

**结论**：
1. 索引可用；两条未命中都是**供给缺口**（考勤、补货），不是检索问题 → 已列入 D 阶段补品。
2. 有 2 条 top-3 混入了不相关项（施工资料命中"工资核算复核"、进口单证命中"滴答清单对接"），说明标签仍需收敛；这是 F1 下一轮（≥95%）的改进点。

## F2 · 五人首跑（需真人，30 分钟/人）

**假设**：在预装好的环境里，财务/法务/HR/采购/行政各 1 人，能用一句话完成一次真实任务，全程不打开终端。

**准备**（组织者，15 分钟）：
1. 一台装有 DSH Web GUI 的机器，已预装：`dsh-einvoice`、`dsh-bankrec`、`dsh-legal-clause`、`dsh-legal-intake`、`dsh-contract-renewal`。
2. 工作区里放 3 个文件：一张合成发票（XML/OFD）、一份银行流水 CSV、一份合同 txt。
3. 打开市场页 `https://perrylink.github.io/dsh-plugins/market.html`。
4. 录屏（只录屏幕，不录声音），记录开始时间。

**任务卡**（任选其一，按受试者岗位）：
- 财务：「把这张发票和这份流水对一下，告诉我重复的是哪张、差多少钱。」
- 法务：「这份合同缺哪些条款？把缺失的列出来。」
- HR：「这 3 份合同里，哪份试用期有问题？」
- 采购：「这两家报价，哪个更便宜？差多少？」
- 行政：「把这份 PDF 里的表格导成 CSV。」

**观察点**（每项打勾）：
| # | 观察点 | 是/否 | 备注 |
|---|---|---|---|
| 1 | 是否打开终端 | | 出现即视为失败路径 |
| 2 | 是否问到"工作区/目录" | | 入口卡点 |
| 3 | 是否找到市场/插件入口 | | 发现卡点 |
| 4 | 是否用了"一句话"而非表单 | | 交互形态 |
| 5 | 是否在 15 分钟内出结果 | | 主判据 |
| 6 | 是否看懂输出（能复述结论） | | 可理解性 |
| 7 | 是否问"数据会不会上传" | | 信任点 |
| 8 | 卡住时第一句话是什么 | | 记录原文 |

**成功判据**：≥3/5 在 15 分钟内完成且全程未开终端；若 ≤1/5，或多数人第一句问"点哪里"，判为**入口问题**，回到 E1/E2 上游需求。

## 自动化替代：`first-run-smoke`

真人实验之前，先用脚本验证"装 → 跑样例 → 出结果"这条路径本身没有断点：

```bash
cd 04-build/dsh-plugins
node scripts/first-run-smoke.mjs            # 对 3 个旗舰包执行
```

它做四件事：`npm pack` 取真实 tarball → 解包到临时目录 → 用 tarball 内的 `samples/quickstart/run.mjs --check` 跑一遍 → 断言金标一致、样例与截图都在包里。任何一步失败即说明"首跑路径"有断点，不需要真人也能发现。
