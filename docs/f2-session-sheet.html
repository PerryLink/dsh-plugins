六、判定口径

成功：≥3/5 在 15 分钟内完成，且全程未打开终端。

判为入口问题：≤1/5 完成，或多数人第一句问"点哪里 / 装在哪"→ 回到上游需求 E1（市场默认可见）与 E2（默认工作区）。

判为包装问题：多数人安装了但卡在"不知道说什么"→ 补一句话话术与详情页示例。

七、组织者清单

  1. 预装 5 个插件，确认 `dsh plugin add` 成功、会话里能看到工具。
  2. 工作区放入 3 个合成文件（不要真实客户数据）。
  3. 打开 https://perrylink.github.io/dsh-plugins/market.html 作为起点页。
  4. 开始录屏（仅屏幕），开始计时。
  5. 只观察，不提示；受试者提问时回答"你觉得呢"（可记录该句）。
  6. 结束后请受试者复述结论，再填写第五节。
