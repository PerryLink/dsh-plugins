# Privacy

This repository is a static index. It has no telemetry, analytics, accounts, or server-side data collection.

- The pages are static HTML; no cookie or tracking script is included.
- Install commands point to npm and GitHub; those services process metadata under their own policies.
- No customer data or customer evidence is stored here.
- The only personal data is the public maintainer contact in `SECURITY.md` and `CODE_OF_CONDUCT.md`.
